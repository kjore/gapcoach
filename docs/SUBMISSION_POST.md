## 一句话介绍

大多数题库只告诉你“对了几道”。知隙回答的是三个更难的问题：我卡在哪个知识点？下次先看哪段材料、为什么是它？上次错的原因能不能带到下一次？它把「10 题诊断 → 薄弱点 → 检索材料 → 练习反馈 → 记忆 → 下次的计划」串成一条闭环。

## 核心功能

1. **入学诊断**：10 题覆盖 5 个知识模块（示例课程：《数据库系统概论》），支持键盘作答与回看。
2. **诊断报告**：各模块掌握度、真正的薄弱点、为什么先补它。
3. **今日计划**：最多 3 组任务，按“掌握度低 + 最近错得多”排序，每组附 2 段检索材料和 2 道练习。
4. **练习反馈**：判分、解析、可引用的**原文证据**、掌握度变化、相似错题。
5. **学习记忆**：答错写入薄弱点记忆，答好写入优势记忆；掌握度 ≥ 85 且连对 ≥ 3 时薄弱记忆**解除**，不是永久贴标签。重新输入同一称呼即可恢复上次状态。
6. **技术轨迹页**：每次检索与记忆读写逐条可查，还能输入任意问题现场看混合检索的分数构成——不是“接了个引擎”，是每次都在用。

## 技术亮点：整套检索与记忆引擎跑在浏览器里

这个项目的第一版是 Python 后端（FastAPI + 嵌入式 seekdb + PowerContext 本地记忆服务）。为了让评委点开链接就能玩，我们把**同样的语义完整移植进了浏览器**，零依赖、零构建、零 API Key：

- **混合检索**：全文通道（分词包含）+ 向量通道（特征哈希 embedding 余弦）→ RRF 融合；综合分数 = 检索分 × 0.72 + 薄弱加权 × 0.28，每条结果公开 `score_parts`。**同一个问题，对不同掌握度的学生返回不同排序。**
- **中文 embedding**：字符 unigram + bigram + ASCII 词 → FNV-1a 特征哈希 → 384 维 L2 归一化，纯本地计算。
- **记忆生命周期**：weakness / strength / session 记忆带 artifact 与 revision，支持解除（resolve），复刻了原后端 PowerContext 的语义。
- **可核对性**：技术轨迹页把每次 `retrieval/*`、`memory/*` 调用摊开；旧版后端的 20/20 端到端验证记录归档在 `docs/legacy/`。
