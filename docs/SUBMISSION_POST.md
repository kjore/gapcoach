## 一句话介绍

大多数题库只告诉你“对了几道”。知隙回答的是三个更难的问题：**我卡在哪个知识点？下次先看哪段材料、为什么是它？上次错的原因能不能带到下一次？** 它把「10 题诊断 → 薄弱点 → 检索材料 → 练习反馈 → 记忆 → 下次的计划」串成一条闭环。

## 它解决什么问题

复习时真正难的从来不是刷题量，而是三件事：

1. **定位**：错的是哪道题不重要，重要的是它暴露了哪个知识点的缝；
2. **选材**：下一步看什么不能靠感觉，要能说出“为什么是这段材料”；
3. **延续**：上次踩的坑如果带不到下一次，每次复习都是从零开始。

知隙的闭环：

```text
10 题诊断 → 掌握度与薄弱点 → 写入学习记忆
      ↓                              ↓
浏览器内混合检索材料与练习 ← 今日计划按薄弱程度排序
      ↓
作答 → 判分 + 原文证据 + 掌握度变化 → 新记忆 → 下次继续
```

## 核心功能（附背后发生了什么）

1. **入学诊断**：10 题覆盖 5 个知识模块（示例课程《数据库系统概论》，5 知识点 / 15 段材料 / 30 题）。支持键盘 `1–4` 选择、`Enter` 继续、回看上一题。
   背后：每个知识点抽 2 题；答对/答错按 ±12 更新掌握度；诊断结束写入 strength / weakness 记忆与 session 摘要。
2. **诊断报告**：五个模块的掌握度条、真正的薄弱点、以及“为什么先补它”的证据句（例如“你在「并发控制与隔离级别」上只答对 0/2 题”）。
   背后：薄弱 = 掌握度 < 60 且已作答；报告同时列出本次写入的学习记忆（含 artifact 编号）。
3. **今日计划**：最多 3 组任务，按“掌握度低 + 最近错得多”排序；每组 2 段检索材料 + 2 道练习，并标注预计时长。
   背后：每组材料来自混合检索（见下节），材料卡片公开检索分与薄弱加权分。
4. **练习反馈**：判分、解析、**可引用的原文证据**（出处到章节）、掌握度变化（如 26 → 11，−15）、相似错题提醒。
   背后：答错写入薄弱点记忆；相似错题用错题文本向量余弦召回；答对 +10（连对 ≥ 2 时 +15）。
5. **学习记忆与恢复**：重新输入同一称呼即恢复上次状态；进度页有完整记忆时间线（计划快照 / 会话摘要 / 薄弱点 / 进步记忆，均带 artifact 与 revision）。
   背后：掌握度 ≥ 85 且连对 ≥ 3 时，对应薄弱记忆**解除**而不是永久贴标签。
6. **技术轨迹页**：把每次检索与记忆读写的 `kind / action / detail` 逐条摊开；还能输入任意问题现场跑一次混合检索，看分数构成。
   背后：会话内环形缓冲 200 条；检索记录含通道、过滤条件与返回分数。

## 技术亮点：整套检索与记忆引擎跑在浏览器里

第一版是 Python 后端（FastAPI + 嵌入式 seekdb + PowerContext 本地记忆服务）。为了让评审点开链接就能玩，我们把**同样的语义完整移植进浏览器**，零依赖、零构建、零 API Key：

- **混合检索**（`engine/retrieval.js`）：
  - 全文通道：中文分词（unigram + bigram + ASCII 词）包含匹配打分；
  - 向量通道：特征哈希 embedding 的余弦相似度；
  - 两路结果做 **RRF 融合**（k=20，窗口 8），再按知识点过滤；
  - 综合分数 = 检索分 × 0.72 + 薄弱加权 × 0.28，每条结果公开 `score_parts`。
  - **同一个问题，对不同掌握度的学生返回不同排序**——薄弱加权来自当前学习者的记忆。
- **中文 embedding**（`engine/embed.js`）：字符 unigram + bigram + ASCII 词 → FNV-1a 特征哈希 → 384 维 L2 归一化，纯本地计算，无外部服务。
- **学习记忆**（`engine/memory.js`）：weakness / strength / session / plan 四类记忆，带 artifact 与 revision，支持生命周期解除；语义复刻自原版 PowerContext 接口。
- **进度存储**（`engine/storage.js`）：作答记录与掌握度落 localStorage；相似错题 = 错题文本向量余弦 Top-K。
- **教练逻辑**（`engine/coach.js`）：诊断选题、计划排序、判分反馈、跨会话恢复，数值规则与原版后端完全一致（初始 50；诊断 ±12；练习 +10/+15/−15；薄弱 <60；稳固 ≥85 且连对 ≥3）。
- **可核对性**：技术轨迹页实时展示每次 `retrieval/*`、`memory/*` 调用；旧版后端 20/20 端到端验证记录归档在 `docs/legacy/` 与 `docs/verification/`。
