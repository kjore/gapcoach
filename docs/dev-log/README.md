## 如果还要补录屏

2–3 分钟即可：打开需求 → 展示一次代码修改 → 运行 `verify.py` → 打开已发布站点。文件名建议 `06-demo.mp4`。

## 截图注意事项

- 只保留 Qoder 对话和必要终端，关闭聊天软件、邮箱、通知等无关窗口；
- 不展示真实姓名、邮箱、手机号、访问令牌；
- 不要用设计稿或生成图代替真实对话；
- 新增截图后，在 [`../DEV_LOG.md`](../DEV_LOG.md) 的「验证证据」一节补索引。
