The problem

它不急着给答案，
先找出你缺的那一块。

复习最贵的不是做题，是在已经会了的地方反复用力。知隙把“下一步练什么”变成一条有证据的路径：诊断定位、检索给材料、记忆负责下一次。

01

诊断不是考试

10 道题覆盖 5 个模块。答错不是扣分，是定位；每次选择都留在 seekdb 里，用于下一轮判断。

02

推荐必须能解释

每段材料和练习都带检索分数：seekdb 召回多少，薄弱加权多少。不是“猜你喜欢”，而是可追问的依据。

03

记忆不是日志

薄弱点、进步、计划快照写进 PowerContext。下一次打开先恢复“你是谁、上次错在哪”，而不是从零开始。

诊断不是考试。它只是把缝找出来。

知隙的界面里，写着这句话

Five screens

一条闭环，五个界面。

从第一次诊断到第二天回来，每一屏都只做一件事。下面的截图来自真实运行，不是设计稿；点击可放大。

SCREEN 01 / DIAGNOSTIC

十道题，先定位，不急着评分。

诊断不是资格测试。题目难度从概念辨认到场景判断，答完立刻得到每个模块的掌握度，而不是一个无法行动的总分。

  • 5 个模块 × 2 题，覆盖事务、索引、SQL、并发、分布式。
  • 支持键盘 1–4 选择、Enter 继续，可回看上一题。
  • 答错写入薄弱点记忆；答对留下进步记录。

seekdb attempts / progress
PowerContext weakness + strength

SCREEN 02 / REPORT

把“你哪里不会”说具体。

报告不先夸你答对了多少，而是回答：最该补哪一块、为什么是它、接下来按什么顺序走。未作答的模块会标“尚待测”，不冒充薄弱点。

  • 标题取真实最低掌握度，而不是固定第一项。
  • “为什么先补这里”引用你的答题记录，而不是模板话术。
  • 末尾列出本次写入 PowerContext 的记忆与 artifact 前缀。

seekdb progress rows
PowerContext memory feed

SCREEN 03 / PLAN

今天只补三个地方。

计划最多 3 组，按“掌握度低 + 最近错得多”排序。每组固定 2 段材料和 2 道练习，把“看懂了”推进到“会做”。

  • 最薄弱的知识点排第一，并说明排序原因。
  • 每段材料公开 检索 / 薄弱加权 分数。
  • 可直接开始本组练习，也可以按最新进度重排。

seekdb hybrid_search · RRF · kp filter
PowerContext plan:current

SCREEN 04 / PRACTICE

答错，也要知道为什么错。

判分不是终点。反馈会给出正确答案、解析、可引用的原文，以及这次作答对掌握度的影响。答错会写入新的薄弱点记忆。

  • 原文证据来自 seekdb，标出检索分与薄弱加权。
  • 相似错题会被一并提示，避免重复踩同一个坑。
  • 练习完成后直接回到计划，记忆已同步。

seekdb materials + similar mistakes
PowerContext return_attempt → remember

SCREEN 05 / PROGRESS

记忆会替你记住。

进度页把学习状态摊开：五个模块的掌握度、最近作答、每条 PowerContext 记忆，以及 seekdb 与记忆服务的实际落点。

  • 展示答题数、正确数、连对，而不是只给一个百分比。
  • 记忆时间线可看到 kind、文本与 artifact 前缀。
  • 数据落点公开数据库状态，方便评审核对。

seekdb stats · attempts
PowerContext atomic-memory timeline

Two engines

两个内核，
各做一件事。

seekdb 决定“拿什么材料”，PowerContext 决定“你是谁、错在哪”。两边都返回可核对的 artifact 与分数，而不是黑箱推荐。

01

seekdb · embedded

材料、题目与作答，
都在一个本地库里。

  • 检索HNSW 余弦向量 + IK 全文，hybrid_search 以 RRF 融合，再按知识点过滤。
  • 数据materials 15 段、questions 30 道、attempts 作答记录、progress 掌握度。
  • 向量本地中文哈希 embedding：字符 unigram + bigram + ASCII 词 → 384 维，不调用外部 embedding API。
  • 解释每次检索返回 retrieval 与 weakness 分数构成。
02

PowerContext · local server

薄弱点与进步，
跨会话留在这里。

  • 隔离每个“学习者 + 课程”一个 Scope；重新进入先恢复 Scope，再检索记忆。
  • 记忆weakness:<kp>、strength:<kp>、session:summary、plan:current。
  • 可追溯每条记忆带 atomic-memory artifact 与 revision，界面显示 artifact 前缀。
  • 会解除掌握度 ≥ 85 且连对 ≥ 3 时，薄弱点走 lifecycle 解除，而不是永久标签。

Reproduce

三步，在自己的
机器上跑起来。

没有构建步骤，没有 LLM Key，没有云数据库。Python 3.11+，macOS 或 Linux；首次安装依赖需要网络，之后完全本地。

01

准备环境

创建 .venv、安装依赖、生成带绝对路径的 .env，并创建数据目录。

cd qoder
./scripts/setup.sh

02

启动两个服务

脚本会先启动 PowerContext（18080），再启动 GapCoach（8000）；退出时清理它启动的进程。

./scripts/start.sh
# 打开 http://127.0.0.1:8000

03

跑一遍验证

另开一个终端。脚本会创建全新学习者，不依赖浏览器截图或演示数据。

.venv/bin/python scripts/verify.py

# VERIFY: PASS — 全链路可复现。

Checklist

你会需要

  • Python3.11+（验证于 3.12.14）
  • 系统macOS / Linux
  • 端口8000 · 18080
  • 网络仅首次安装依赖
  • API Key不需要

本地优先。应用使用嵌入式 seekdb 与本地 PowerContext；公开站是项目说明与真实运行截图，完整体验请按左侧步骤在本地启动。源码包包含完整代码、运行说明与开发记录。
